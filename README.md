# FinSMPro Omega — Flutter Client

## التشغيل (على جهازك، Flutter SDK غير متاح في بيئتي هنا)
```bash
flutter pub get
# عدّل kServerBaseUrl في lib/providers/app_providers.dart لرابط سيرفرك
flutter run
```

## ما تم بناؤه الآن (شغّال ومترابط، مو placeholder)
- **تخزين محلي كامل (SQLite)**: مراكز، صفقات مغلقة، كاش أسعار، قائمة
  مراقبة، سجل brain، عمليات معلّقة بانتظار المزامنة، إعدادات.
- **عميل API عام** يغطي كل الـ 40+ مسار بالسيرفر عبر `get()/post()`،
  بالإضافة لدوال مختصرة لأهم المسارات (portfolio, positions, buy, sell...).
- **بث أسعار حي**: SSE أولاً (بعد إضافة `/api/price_stream`، راجع
  `server_todo.md`)، وfast-poll كل 3 ثوانٍ كخطة احتياطية — بدل تأخير
  الكاش الحالي 30 ثانية.
- **آلية أوفلاين**: أي عملية (شراء/بيع) تفشل بسبب انقطاع النت تُخزَّن
  بجدول `pending_ops` وتُعاد تلقائياً عند عودة الاتصال.
- **شاشة المحفظة**: تفتح فوراً من البيانات المحلية (لا شاشة فارغة)،
  ثم تتحدث لحظياً وتُظهر مصدر السعر وعمره بالثواني لكل سهم.

4. **شاشة المحفظة والمخاطر** (`RiskScreen`).
5. **شاشة عقل الآلي الحية** (`BrainLogScreen`).
6. **شاشة الشات مع AI** (`ChatScreen`).
7. **شاشة الإعدادات** (`SettingsScreen`).
8. **مزامنة تلقائية للعمليات أوفلاين** (`SyncService`).
9. **تشخيص اتصال حقيقي بدل شاشة فارغة صامتة**:
   - `/api/health` جديد بالسيرفر — يفصل بوضوح بين "السيرفر لا يستجيب"
     و"السيرفر يعمل لكن قاعدة البيانات معطّلة"، كل حالة ببانر بلون مختلف
     (أحمر/برتقالي) بأعلى التطبيق بدل الابتلاع الصامت للخطأ.
10. **🔒 إصلاح أمني مهم بالسيرفر** — كانت هناك **نسختان** من رابط
    قاعدة بيانات Neon (بكلمة المرور صريحة) مكتوبتان كـ fallback بالكود:
    - الثابت العام `PG_URL` بأعلى الملف.
    - `DB._load_url()` بكلاس `DB` (وهي المستخدمة فعلياً بمعظم الشاشات).
    كلاهما الآن يعتمد فقط على `DATABASE_URL` بمتغيرات البيئة، ويفشل
    بوضوح عند غيابه بدل الرجوع لبيانات اعتماد مكتوبة بالكود.
    **⚠️ إجراء مطلوب منك يدوياً بلوحة Neon:** غيّر كلمة مرور قاعدة
    البيانات فوراً لأنها كانت مُسرَّبة بالملف، ثم حدّث `DATABASE_URL`
    بمتغيرات بيئة Render بالقيمة الجديدة.
